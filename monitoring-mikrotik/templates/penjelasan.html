Tentang NETMON

NETMON merupakan sistem monitoring jaringan berbasis web yang digunakan untuk menampilkan informasi dan kondisi perangkat MikroTik melalui dashboard yang mudah dipantau.

Tujuan Sistem

NETMON dibuat untuk membantu administrator jaringan memantau informasi dasar perangkat MikroTik secara terpusat melalui halaman web. Sistem ini menampilkan informasi seperti alamat IP, versi RouterOS, penggunaan CPU, penggunaan memori, uptime, interface, dan traffic jaringan.

Fitur NETMON

01. Router Information Menampilkan nama router, IP address, versi RouterOS, dan uptime.
02. CPU Monitoring Menampilkan persentase penggunaan CPU untuk melihat beban sistem router.
03. Memory Monitoring Menampilkan persentase penggunaan memori pada perangkat MikroTik.
04. Network Interface Menampilkan status interface seperti ether1, ether2, dan wlan1.
05. Traffic Monitor Menampilkan informasi traffic download dan upload jaringan.
06. IP Configuration Memungkinkan administrator mengubah IP yang digunakan dalam konfigurasi NETMON.

Cara Kerja NETMON

NETMON menggunakan Flask sebagai server aplikasi. Browser mengakses dashboard melalui server Flask. Data monitoring disimpan dalam konfigurasi aplikasi dan kemudian ditampilkan pada halaman dashboard.

Browser ↓ NETMON Dashboard ↓ Flask / app.py ↓ Data Router ↓ Dashboard Monitoring

Kesimpulan

Dengan adanya NETMON, informasi dasar perangkat jaringan dapat ditampilkan dalam satu dashboard sehingga proses pemantauan menjadi lebih mudah, terstruktur, dan cepat.
